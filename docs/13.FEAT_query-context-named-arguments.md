# Query Context Named Arguments

## Description

`Query::QueryContext` now uses named constructor arguments so bucket, scope, and
namespace values are explicit at the call site. `bucket:` is required, while
`scope:` and `namespace:` are optional and default to `_default` and `default`.
This keeps manual query context construction readable and avoids relying on
positional ordering for Couchbase's bucket/scope hierarchy.

## Implementation

- Changed `Query::QueryContext.new` to require keyword arguments.
- Updated the Query context shorthand internals to construct `QueryContext` with
  named `bucket:`, optional `scope:`, and optional `namespace:` arguments.
- Updated specs, shared example helpers, and README snippets to use the named
  constructor style.
