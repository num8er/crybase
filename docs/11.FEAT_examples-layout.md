# Examples Layout

## Description

The examples layout keeps runnable examples small by moving each example into
its own directory and placing reusable setup code under `examples/shared`.
Runnable entry points now live at `examples/<example_name>/example.cr`.

## Implementation

- Moved every runnable Crystal example from `examples/*.cr` into
  `examples/<example_name>/example.cr`.
- Moved shared environment constants to `examples/shared/constants.cr`.
- Moved shared connection builders, client openers, query context helpers, and
  seeded `User` helpers to `examples/shared/methods.cr`, with each helper in
  `examples/shared/methods/<method_name>.cr`.
- Moved shared `Profile`, `User`, and `UserRow` types under
  `CryBaseExamples::Structs`, with `examples/shared/structs.cr` as the entry
  point and each struct in `examples/shared/structs/<name>.cr`.
- Moved the shared ULID generator to `examples/shared/ulid.cr`.
- Added short private aliases inside runnable examples for client classes,
  shared structs, and the shared examples module.
- Updated integration specs and documentation to require the new shared files.
