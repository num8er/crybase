# KV Client Pool

## Description

The KV client pool provides a fixed-size set of authenticated `KV::Client` connections for concurrent fibers. It keeps the public KV operation surface available on the pool while checking out one client per operation and returning it after use.

## Implementation

- Added `KV::Pool` with a default size of 10 authenticated clients.
- Added `Pool.from_string` for the same connection-string credentials, bucket, and TLS options used by `KV::Client.from_string`.
- Added a channel-backed checkout flow that yields a client and returns it to the pool after the block completes.
- Added pool lifecycle state with `closed?` and idempotent `close`.
- Added `KV::ClientDelegator` to generate forwarding methods from `KV::Pool` to checked-out clients.
- Added specs for pool construction, lifecycle, checkout behavior, and delegated public methods.
