# KV Bucket Config Vbucket Count

## Description

KV clients now use bucket-specific vbucket counts when they can load Couchbase
bucket config from Management. This prevents document and counter requests from
hashing keys with the historical 1024-vbucket default when a bucket reports a
different `numVBuckets` value, such as 64.

## Implementation

- Added `KV::BucketConfig` for parsing bucket config JSON from
  `/pools/default/buckets/<bucket>`.
- Added `KV::BucketConfigClient` for authenticated Management requests through
  the shared connectivity HTTP client.
- Added `KV.management_endpoints` and `KV.discover_vbucket_count` helpers for
  deriving Management endpoints from Couchbase connection strings.
- Added `vbucket_count` state to `KV::Client`, `KV::Pool`, and `KV::Cluster`.
- Updated `KV::Client.from_string`, `KV::Pool.from_string`, and
  `KV::Cluster.from_string` to discover `numVBuckets` by default and pass the
  count into document-operation hashing.
- Kept explicit `vbucket_count:` and `discover_bucket_config: false` options
  for callers that construct clients in environments without Management access.
- Added unit coverage for config parsing, HTTP fetch behavior, Management
  endpoint derivation, and the `User::seq_no` vbucket calculation against a
  64-vbucket bucket.
