# Query Connection Defaults

## Description

Query clients and clusters can define global bucket/scope defaults with
assignment-style setters. Query connection strings can also include a bucket
path, such as `couchbase://user:pass@node1/commerce`, which becomes the default
Query bucket.

## Implementation

- Added `bucket=` and `scope=` on `Query::Client` and `Query::Cluster`.
- Updated `Query::Client.from_string` and `Query::Cluster.from_string` to read
  the parsed connection string bucket path as the default Query bucket.
- Added named `bucket:` overrides to Query `from_string` constructors so callers
  can override the URI bucket path.
- Kept `bucket(...).scope(...)` as a non-mutating scoped context helper for
  one-off Query operations.
- Updated Query specs, integration helpers, examples, README, and manuals.
