# Key Value Service

Use KV when the application already knows the document key.

## One Connection

```crystal
require "crybase"

kv = CryBase::CouchBase::KV::Client.from_string(
  "couchbase://Administrator:password@127.0.0.1/commerce",
)

kv.set("user:1", %({"name":"Ada"}))
puts String.new(kv.get("user:1"))
kv.touch("user:1", 3600_u32)
kv.delete("user:1")
kv.close
```

The bucket is selected during connection setup. Use `kv.bucket = "other-bucket"`
to switch the active bucket on the connection.

## Scoped Collections

Use assignment when direct KV operations should use connection-level defaults:

```crystal
kv.bucket = "commerce"
kv.scope = "ecommerce_shop"
kv.collection = "users"

kv.set("user:1", %({"name":"Ada"}))
puts String.new(kv.get("user:1"))
```

Use `scope(...).collection(...)` when only one context should target a specific
Couchbase collection:

```crystal
users = kv.scope("ecommerce_shop").collection("users")

users.set("user:1", %({"name":"Ada"}))
puts String.new(users.get("user:1"))
users.delete("user:1")
```

`collection(...)` uses the current global scope and returns a context without
changing the global collection:

```crystal
kv.scope = "ecommerce_shop"
users = kv.collection("users")
```

`KV::Client`, `KV::Pool`, and `KV::Cluster` all expose `bucket=`, `scope=`,
`collection=`, `scope(...)`, and `collection(...)`.

## Typed Values

```crystal
require "json"
require "crybase"

struct Profile
  include JSON::Serializable

  getter name : String
  getter score : Int32

  def initialize(@name : String, @score : Int32)
  end
end

kv.set("profile:1", Profile.new("Ada", 42))
profile = kv.get_as("profile:1", Profile)
puts profile.name
```

## Pool

Use `KV::Pool` when multiple fibers need short KV operations:

```crystal
pool = CryBase::CouchBase::KV::Pool.from_string(
  "couchbase://Administrator:password@127.0.0.1/commerce",
  size: 20,
)

pool.set("counter", "1")
pool.scope = "ecommerce_shop"
users = pool.collection("users")
users.set("user:1", %({"name":"Ada"}))

pool.checkout do |client|
  puts String.new(client.get("counter"))
end

pool.close
```

## Seed Failover

Use `KV::Cluster` for seed failover:

```crystal
cluster = CryBase::CouchBase::KV::Cluster.from_string(
  "couchbase://Administrator:password@node1,node2,node3/commerce",
)

cluster.set("crybase:cluster", "value")
cluster.scope = "ecommerce_shop"
users = cluster.collection("users")
users.set("user:1", %({"name":"Ada"}))

puts String.new(cluster.get("crybase:cluster"))
cluster.close
```

`KV::Cluster` is seed failover only. Vbucket-map routing is not implemented
yet.
