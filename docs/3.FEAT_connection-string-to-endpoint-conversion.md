# Connection String To Endpoint Conversion

## Description

Connection string to endpoint conversion turns Couchbase-style URIs into typed endpoint values. It supports plaintext and TLS Couchbase schemes, HTTP(S) management URLs, multiple seed hosts, optional per-host ports, credentials, bucket names, and query parameters used by KV helpers.

## Implementation

- Added `ConnectionString.parse` for `couchbase://`, `couchbases://`, `http://`, and `https://` inputs.
- Added parsing for `user:pass@host`, comma-separated hosts, optional ports, bucket path, and query parameters.
- Added `ConnectionString#param` and `#bool_param` for typed query option access.
- Added `Endpoint.from_string` to return a concrete endpoint for the first parsed host.
- Added service default-port selection so KV and Management endpoints use the expected plaintext or TLS ports.
- Updated the cluster-level `Client` to build a host-by-service endpoint matrix from parsed connection strings.
