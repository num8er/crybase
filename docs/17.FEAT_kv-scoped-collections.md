# KV Scoped Collections

## Description

KV clients, pools, and clusters can target Couchbase scoped collections with
`scope(...).collection(...)` wrappers. They can also keep connection-level
bucket, scope, and collection defaults for direct KV operations.

## Implementation

- Added `KV::ScopeContext` and `KV::CollectionContext`.
- Added `scope(name)` on `KV::Client`, `KV::Pool`, and `KV::Cluster`.
- Added `bucket=`, `scope=`, `collection=`, and `collection(name)` on
  `KV::Client`, `KV::Pool`, and `KV::Cluster`.
- Added collection-aware binary key encoding with unsigned LEB128 collection
  IDs.
- Negotiated Couchbase collection support during KV `HELLO`.
- Added collection manifest lookup and per-client collection ID caching.
- Kept context helpers non-mutating: `scope(...).collection(...)` and
  `collection(...)` return collection contexts, while assignment methods update
  connection-level defaults.
- Added unit coverage for key encoding, context wrappers, and delegated KV
  operation signatures.
- Added integration coverage for default scoped collection KV operations.
