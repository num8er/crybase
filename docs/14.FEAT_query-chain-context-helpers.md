# Query Chain Context Helpers

## Description

Chainable Query context helpers let callers keep bucket and scope selection next
to repeated Query operations. `client.bucket("bucket").scope("scope").query(...)`
maps to the existing Couchbase Query `query_context` option without changing the
lower-level `query(..., bucket:, scope:)` shorthand.

KV scoped collection helpers are a separate KV protocol feature because they
resolve collection IDs and encode collection-aware document keys instead of
using the Query service `query_context` option.

## Implementation

- Added `Query::BucketContext` and `Query::ScopeContext` wrappers.
- Added `bucket(name, namespace: ...)` on `Query::Client` and `Query::Cluster`,
  with `namespace:` optional and defaulting to `default`.
- Kept chain contexts non-mutating; assignment setters update connection-level
  defaults.
- Delegated Query statement, typed-row, streaming, cursor, prepare, and prepared
  execution helpers through `ScopeContext` with a fixed `QueryContext`.
- Added unit coverage for direct Query clients and Query clusters.
- Updated README and CHANGELOG documentation.
