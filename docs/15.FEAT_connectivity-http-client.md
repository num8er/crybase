# Connectivity HTTP Client

## Description

`CryBase::Connectivity::HTTPClient` centralizes HTTP client construction over
the shared Connectivity socket layer. Query service code still owns N1QL form
building, response parsing, connection reuse, and failover behavior, but it no
longer creates `HTTP::Client` instances directly.

## Implementation

- Added `CryBase::Connectivity::HTTPClient.open` for host/port and `host:port`
  HTTP client construction.
- Added optional HTTP basic-auth setup to the shared helper.
- Added `Connectivity::HTTPClient.reconnect_error?` so Query reconnect handling
  does not depend on an HTTP-client error string locally.
- Refactored `Query::Client` and `Query::TopologyClient` to build HTTP clients
  through `CryBase::Connectivity::HTTPClient`.
- Added connectivity specs for HTTP client creation and basic auth.
- Updated README and CHANGELOG documentation.
