# KV Cluster

## Description

The KV cluster layer adds seed failover for KV operations. It accepts a multi-host Couchbase connection string, builds one seed endpoint per host, keeps one active `KV::Pool`, and switches to another seed when pool creation or a delegated operation fails with a connection-level error.

## Implementation

- Added `KV::Cluster` with the same delegated KV operation surface as `KV::Pool`.
- Added `Cluster.from_string` to read credentials, bucket, TLS settings, and multiple seed hosts from one URI.
- Added `Cluster.seed_endpoints` to convert parsed hosts and ports into KV endpoints.
- Added active-pool tracking, failover sequencing, lifecycle handling, and close behavior.
- Kept the implementation explicitly limited to seed failover; vbucket-map routing and cluster config loading remain future work.
- Added specs and examples covering multi-seed setup, failover behavior, and public API delegation.
