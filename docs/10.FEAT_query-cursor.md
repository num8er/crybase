# Query Cursor

## Description

Query cursors provide an explicit object-oriented streaming API for SELECT
queries. Callers can create a cursor with `query_cursor(...)`, pass it around,
and consume rows with `cursor.each` or `cursor.each_as(Type)` without changing
the eager `query(...)` result API.

## Implementation

- Added `Query::Cursor`, a single-use streaming row cursor that stores the
  final `Query::Result` after successful consumption.
- Added `Query::Client#query_cursor` and `Query::Cluster#query_cursor`.
- Implemented cursors on top of the existing `query_each` streaming path, so
  rows are yielded while `Result.from_stream` parses the HTTP response body.
- Added typed cursor consumption through `Cursor#each_as(Type)`.
- Added unit coverage for cursor typing, single-use behavior, cluster
  delegation, and yielding the first row before a streamed HTTP response
  finishes.
- Added dedicated real Couchbase Query integration coverage that consumes
  seeded `User` rows through `query_cursor`.
- Added `examples/query_cursor/example.cr` and updated README Query
  documentation with cursor usage.
