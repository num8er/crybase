# KV Default Context

## Description

KV clients, pools, and clusters can keep connection-level bucket, scope, and
collection defaults. Direct KV operations use those defaults, while
`scope(...).collection(...)` and `collection(...)` return explicit collection
contexts without changing the defaults.

## Implementation

- Added `bucket=`, `scope=`, and `collection=` on `KV::Client`, `KV::Pool`, and
  `KV::Cluster`.
- Added `collection(name)` on `KV::Client`, `KV::Pool`, and `KV::Cluster`; it
  resolves the collection in the current default scope.
- Kept `scope(name)` as a non-mutating context helper.
- Updated direct KV document, expiration, counter, and typed value operations
  to use the connection-level collection default when no explicit collection ID
  is passed.
- Propagated pool and cluster defaults to checked-out clients.
