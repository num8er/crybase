# KV Client

## Description

The KV client is the first service-specific Couchbase protocol client in CryBase. It connects to one Couchbase KV node over plaintext or TLS, authenticates with SASL PLAIN, selects a bucket, and exposes document operations for `get`, `set`, `delete`, `touch`, get-and-touch, counters, and typed value helpers.

## Implementation

- Added the `CryBase::CouchBase::Services::KV` namespace for Couchbase binary protocol support.
- Added protocol constants, opcodes, statuses, request values, response values, request-buffer serialization, and response decoding.
- Added `KV::Client`, composed from `RequestWriter`, `ResponseReader`, and `Bucket`.
- Added startup handshake flow: socket open, optional TLS wrap, `HELLO`, `SASL_AUTH`, and `SELECT_BUCKET`.
- Added KV document operations and counter helpers using vbucket hashing.
- Added `KV::Client.from_string` for credentials, bucket, TLS mode, and TLS options from connection strings.
- Added typed JSON helper support through `KV::Serializable`, `set(key, value)`, and `get_as(key, Type)`.
