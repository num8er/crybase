# Query Default Context

## Description

Query clients and clusters can now keep a default bucket/scope context at the
connection level. This supports setup such as `client.bucket = "bucket"` and
`client.scope = "scope"`, then later `client.query(...)` calls without repeating
the same context on every operation.

## Implementation

- Added connection-level default bucket and scope state to `Query::Client` and
  `Query::Cluster`.
- Added `bucket=` and `scope=` on `Query::Client` and `Query::Cluster` to store
  global Query context defaults.
- Kept `bucket(name).scope(name)` as the chainable bucket/scope context wrapper.
- Resolved Query context precedence as explicit `query_context:`, then
  per-query `bucket:`/`scope:`, then connection defaults.
- Added unit coverage for direct Query clients and Query clusters.
- Added integration coverage for resolving collection queries through
  connection-level bucket/scope defaults.
- Updated README and CHANGELOG documentation.
