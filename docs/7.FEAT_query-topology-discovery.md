# Query Topology Discovery

## Description

Query topology discovery lets `Query::Cluster` load Couchbase Query service nodes from the Management API's `/pools/default/nodeServices` endpoint. Clusters built from connection strings still keep their original Query seed endpoints as fallback, but they can now route to the discovered Query nodes and refresh topology when nodes change.

## Implementation

- Added `Query::Topology` to parse Couchbase `nodeServices` JSON into Query `Endpoint` values.
- Added `Query::TopologyClient` to fetch `nodeServices` over authenticated HTTP/HTTPS through the shared connectivity layer.
- Added `Query::Cluster.management_endpoints` for Management seed endpoint construction.
- Updated `Query::Cluster.from_string` to enable topology discovery by default, with `discover_topology:`, `management_port:`, and `network:` options.
- Added `Query::Cluster#refresh_topology` for explicit topology refresh.
- Updated Query cluster failover to refresh discovered endpoints after transport failures or retryable Query service errors.
- Preserved static seed failover for direct `Query::Cluster.new` usage and as fallback when topology discovery is unavailable.
